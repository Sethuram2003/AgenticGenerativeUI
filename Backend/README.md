
# Backend (LangGraph + Ollama)

This backend streams OpenAI-compatible chunks generated by a LangGraph pipeline
that runs on a local Ollama model.

## Environment

- `OLLAMA_HOST` (default: `http://localhost:11434`)
- `OLLAMA_MODEL` (default: `minimax-m2.1:cloud`)
- `OLLAMA_TEMPERATURE` (default: `0.2`)

## Run

```bash
uvicorn main:app --reload --port 8000
```
